# Taxi Demand Forecasting

Forecasting the number of airport taxi orders one hour ahead.

## Result

CatBoost achieved test RMSE = 39.54, compared with 58.8 for the naive baseline.

## What this project demonstrates

Time series, lag features, rolling statistics, timeseriessplit, catboost, rmse.

## Notebook

See [`taxi_demand_forecasting.ipynb`](taxi_demand_forecasting.ipynb) for the complete analysis.
